# Mini LLM Systems Runtime

Mini LLM Systems Runtime is a compact project for studying language-model
implementation, optimized kernels, distributed training, and future inference
runtime components.

The project is currently at the packaging-scaffold stage. The completed
coursework implementations remain immutable under `legacy/` and will be
migrated incrementally with their existing numerical tests.

The production package uses the `src/mini_llm_runtime/` layout and is managed
with `uv`.
